How to get set up:

1. Import sptravel.sql to mysql workbench, the database name is sptravel
2. Change login info in model/databaseConfig.js to the correct username and password. By default it is set to "root" and "password" respectively.
3. Run ./server.js. The server will be hosted on localhost:8081

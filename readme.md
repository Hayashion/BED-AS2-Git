How to get set up:

1. Import sptravel.sql to mysql workbench, the database name is sptravel
2. Change login info in model/databaseConfig.js to the correct username and password.
3. Open a command prompt window in both ./backend and ./frontend folders
4. Run nodemon backend.js and nodemon frontend.js in their respective folders through command prompt.
5. You will land on login.html, login with an account

Backend is hosted on localhost:8081
Frontent is hosted on localhost:3001

Website access is localhost:3001
